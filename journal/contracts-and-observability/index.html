A query is a contract worth documenting

Notes on working across frontend and orchestration boundaries.

By Derrique Baluyut · October 28, 2026

From the work

Production engineering, design, and the practice around the code.

Beyond the query text

On Pet Pharmacy and Benefit Engagement, I designed GraphQL queries, maintained schemas and orchestration-layer contracts, and used Postman and Splunk for investigation. This work brought service behavior, frontend needs, and documentation into the same conversation.

Keep the boundary understandable

A useful contract makes the information exchanged between layers understandable. When changes span those layers, high-level designs and maintained documentation provide context that code alone may not communicate.

Pair delivery with investigation

Testing and observability answer different questions. Unit and integration testing help check expected behavior; logs, alerts, and dashboards help investigate behavior in a running system. My Benefit Engagement work included creating feature-related Splunk alerts and dashboards. No production logs or internal contracts are included in this note.
